DevExtreme PHP Data

Server-side filtering, sorting, paging, grouping and summaries for DevExtreme widgets — every request below is answered by this library.

DataGrid (SQL)

3000 orders in SQLite. Remote paging, sorting, filter row, header filters, search, grouping, group & total summaries and full CRUD.

PivotGrid (SQL)

Remote pivot over the same table: year / quarter / month date intervals and sum, count, avg summaries executed by GROUP BY.

In-memory array

The same loader on a plain PHP array: DataGrid plus a paged, searchable SelectBox. No database.
Endpoints live in demo/api/; the database is created on first request in demo/data/.
